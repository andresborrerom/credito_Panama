Cobertura y profundidad

La base usa la ventana 10 años completa de la API de Latinex. La profundidad por bucket no se pierde al ampliar la ventana — lo que pasa es que en los primeros 2–3 años (2017–2019) había menos liquidez registrada, especialmente en bonos hipotecarios y notas corporativas. Por eso:

  • Curvas actuales se calculan con últimos 90 días.
  • Series temporales se agregan a frecuencia trimestral con mínimo 3 trades por celda.
  • Percentiles históricos se calculan sobre los últimos 5 años (1,825 días).

Cálculo de YTM

Para cada trade de bono a tasa fija con info completa, se reconstruyen los flujos hasta vencimiento (cupón × frecuencia + amortización bullet al vencimiento), y se resuelve por bisección la tasa que iguala el VP de flujos al precio limpio negociado. Bases soportadas: 30/360, ACT/360, 365/360, ACT/365, ACT/ACT.

Proxy de crédito

No tenemos feed de calificaciones licenciado. Construimos un proxy basado en sector + tipo de instrumento:

  • AAA-PAN-Sov: Bonos del Tesoro, Notas del Tesoro, Letras del Tesoro
  • BBB-Bank: Sector Financiero
  • BBB-Corp: Comunicaciones, Energía, Utilidades
  • BB-Corp: Consumo, Industrial, Servicios, Salud
  • BB-RealEstate: Bienes Raíces (Bonos Hipotecarios)

Adicionalmente, el spread negociado vs Tesoro mismo bucket se reporta como medida revealed-market del riesgo.

Limitaciones

  • Precios = transacciones pactadas, no order book continuo — hay ruido en yields individuales. Se mitiga con medianas por bucket.
  • Calificaciones públicas reales (Fitch, Moody's, Equilibrium) no se incorporan en esta versión — quedan pendientes.
  • Bonos con call/put options se tratan como bullet salvo evidencia desde /pago endpoint.
  • Bonos a tasa variable se excluyen de las curvas (no se puede calcular YTM bullet con cupones flotantes futuros sin asumir trayectoria de la tasa de referencia).
  • Tasas cupón reportadas en 0% se interpretan como cero-cupón o data missing (revisar caso por caso).

Reproducibilidad

El pipeline completo es:

  1. python -m src.etl.extract — descarga raw JSON de Latinex + UST
  2. python -m src.etl.transform — normaliza, calcula YTM, escribe SQLite + Parquet
  3. python -m src.app.build_site — regenera este sitio estático
  4. streamlit run src/app/streamlit_app.py — herramienta interactiva con filtros completos
  5. python -m src.app.build_pdf — genera el PDF descargable

La base completa está versionada en el repo. Cada vez que se quiera refrescar, basta con re-ejecutar los pasos 1–3.
